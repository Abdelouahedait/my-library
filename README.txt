My Private Library - personal 3D PDF library

HOW TO OPEN
1. Unzip the folder (keep the "libs" folder next to index.html).
2. Double-click index.html. Chrome, Edge or Firefox work best.
   No internet connection is needed.

USING IT
- Click "Step inside", walk with W A S D, look with the mouse.
- "+ Add PDF" (or press B) to put your own PDF books on the two shelves.
- Click a book to pick it up, then Read / Edit / Remove.
- Your books are stored inside the browser (IndexedDB), on this device only.
  Clearing the browser's site data for this page deletes them, so keep your original PDFs.
- If your browser blocks storage for local files, run a tiny local server instead:
    python3 -m http.server 8000   (then open http://localhost:8000)
